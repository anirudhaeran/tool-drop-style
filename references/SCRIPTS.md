# Tool-Drop scripts: the formula (inspired by Nick Sarev's public reels)

How these scripts are built, so we can write our own. This covers the writing only; the edit is in `STYLE.md`.
The full scripts of the reference reels are not included; this file keeps the formula, hook formats, techniques and templates.

---

## 2. The shared formula

All three follow the same skeleton:

```
HOOK (2.5–5 s) → VALUE / "it's free" → PROOF (a big specific number) → HOW IT WORKS (3–5 sequenced steps or items)
→ the "EVEN …" line (objection killer) → [PAYOFF] → CTA (comment KEYWORD → DM)
```

| Beat | Ref 1 | Ref 2 | Ref 3 | Purpose |
|---|---|---|---|---|
| Hook | news drop | warning / command | "you don't need to pay" | stop the scroll, name a brand people know |
| Free / value | "completely free" | "free AI tokens", "without paying an additional cent" | "completely 100% free" | removes the cost objection. **3/3** |
| Proof number | 7,000 issues, 20,000 stars | 7 billion tokens, 600 models | 18 million downloads | credibility in one line. **3/3** |
| Sequence | Just → Then → And then → So → And finally | First → The second → Third → And the fourth → And finally | Just → How to do it? → Plus | gives the listener a ladder to follow. **3/3** |
| "Even …" | "even prompt injection if your app uses AI" | "even gated platforms like LinkedIn…" | "even if you're on a Mac" | answers the "but does it work for me?" doubt. **3/3** |
| CTA | comment "audit" | comment "Claude" | comment "LTX" | comment-to-DM automation. **3/3** |

## 3. Hooks: three formats that work

1. **News drop**: `[Big brand] just [open-sourced / released / launched] [thing] that [does painful job] for your [thing you own].`
   For example, "Cloudflare just open-sourced an AI skill that finds security holes in your vibe-coded app."
2. **Warning / command**: `Don't use [popular tool] until you've [done/installed] these [N] [things].`
   For example, "Don't use Claude Code until you've installed these five plugins."
3. **Cost negation**: `You don't need to pay for [expensive known tool A] or [B] to [outcome] anymore.`
   For example, "You don't need to pay for Veo or Kling to make AI videos anymore."

What all three share:
- **A brand name in the first 1–5 words**: Cloudflare, Claude Code, Veo/Kling.
- **"You/your" in the first sentence.**
- **No greeting, no introduction, no "in this video".**
- **The hook is one sentence, 10–20 words**, and it's finished by 2.6–4.9 s.
- **It's a claim, not a question.**
- The hook names the audience implicitly: vibe-coders, Claude Code users, AI video makers.

## 4. Body techniques

- **One sentence = one visual beat.** Each sentence introduces exactly one new thing that can be shown: a logo, a number, a screen or a list. Nothing in the script is abstract or impossible to show.
- **A specific, large number in every video.** For example "over 7,000", "20,000 stars", "7 billion", "over 600", "18 million", "100%". Usually preceded by **"over"**.
- **Plain-language benefit right after the name.** The pattern is `[Name], which [does X for you]`: "Strix, which attacks your vibe-coded app just like a real hacker…" ("which" appears 4× in ref 2).
- **Simple stacked connectors** instead of transitions: *just, then, and then, so, and finally, plus*. A sentence often chains 2–3 clauses with "so" / "and", so it never pauses.
- **The "even …" line** (3/3) pre-empts the doubt: "even if you're on a Mac", "even gated platforms", "even prompt injection".
- **A mini story or contrast** for credibility. "They originally built it for themselves" (an insider tool, now yours). "Their previous version pulled in 18 million downloads" (a track record). "Official Anthropic plugin" (authority).
- **Concrete examples in lists of 3–4.** "logins, database and APIs"; "LinkedIn, Instagram, X and Reddit"; "skills, hooks, subagents and MCP servers".
- **An emotional phrase per video, used as the emphasis caption.** "completely free", "re-explain a single thing", "100% free", "anymore". These are the phrases that get the gradient emphasis captions in the edit.
- **Talking up to the viewer.** "you/your" appears 7–17 times per video, while "I" appears only once, in the CTA.

## 5. CTA and post caption

**The spoken CTA is identical across all three** (3/3):

> "So if you (guys) want [this / them all / to try this] for yourselves, just comment **[KEYWORD]** down below and I'll [DM / send] you the link directly."

- The keyword is a single word tied to the topic (AUDIT, CLAUDE, LTX). It's easy to type and works as an automation trigger.
- The CTA lasts the final 3.5–4 s. On screen it shows as an emphasis caption: `comment` / `"KEYWORD"`.

**The Instagram post caption** follows its own formula:

> `Comment [KEYWORD] to get [this free X / all these N Y] [to outcome].` + a blank line + the full script.

For example: "Comment AUDIT to get this Free AI skill to fix security holes in your vibe coded apps."

## 6. Numbers to aim for

| | Ref 1 | Ref 2 | Ref 3 | Target |

| Words | 166 | 189 | 111 | **110–190** |

| Sentences | 8 | 9 | 7 | **7–9** |

| Steps / items | 4 | 5 | 2 + bonus | **3–5** |

## 7. Templates

### A. Single tool ("news drop" or "cost negation")

```
HOOK:   [Brand] just [released/open-sourced] [tool type] that [does painful job] for your [thing].
        — or —  You don't need to pay for [A] or [B] to [outcome] anymore.
VALUE:  And it's completely free.   /   Just use [this open-source X] instead, called [Name].
PROOF:  [Origin or track record] — over [BIG NUMBER] [unit], and it's already [social proof number].
HOW:    Just [step 1] and it'll [result].
        Then it'll [step 2], from your [a], [b] and [c], even [edge case] if [condition].
        And then [step 3].
        So [payoff in plain words].
        And finally, it'll [step 4 / final output].
CTA:    So if you want this for yourselves, just comment "[KEYWORD]" down below and I'll DM you the link directly.
```

### B. Listicle ("warning / command")

```
HOOK:   Don't use [popular tool] until you've installed these [N] [things].
ITEM:   First is [Name], which [benefit with a big number]. So [what that means for you].
ITEM:   The second is [Name], which [benefit, using a comparison: "just like a real hacker"].
ITEM:   Third is [Name], which [benefit], so [you never have to do annoying thing].
ITEM:   And the fourth is [Name], which lets you [benefit], even [edge case], all without paying [a cent].
ITEM:   And finally, there's [Name]. It's an official [authority] [thing] that [benefit].
CTA:    So if you want them all for yourselves, just comment "[KEYWORD]" down below and I'll send you the link directly.
```

## 8. Script checklist (before recording)

- [ ] Brand name in the first 5 words; "you/your" in sentence 1; no greeting
- [ ] Hook is done within 3–5 s (10–20 words)
- [ ] The word "free" (or "without paying") appears at least once, and early
- [ ] At least 2 big specific numbers, each starting with "over …"
- [ ] Steps/items use the connector ladder (just / then / and then / so / and finally; or first / second / third / fourth / finally)
- [ ] One "even …" line that answers the main doubt
- [ ] Every sentence names something you can **show** (logo, screen, number, list)
- [ ] One or two emotional phrases marked for emphasis captions
- [ ] CTA uses the exact formula with a single-word keyword
- [ ] 110–190 words total, which comes to 28–46 s at about 250 wpm once pauses are cut
